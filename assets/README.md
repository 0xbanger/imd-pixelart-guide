# Step illustrations

Four transparent **64×64 PNGs**, displayed at native size beside the guide's
four main steps. They are decorative: the headings and instructions carry all
setup information. The images are bundled locally and load without an external
image service.

| File | Scene |
| --- | --- |
| `icons/01-prepare.png` | A frog using a terminal computer. |
| `icons/02-build.png` | A small IMD-inspired robot assembling blocks. |
| `icons/03-register.png` | The frog connecting the art tool to a server. |
| `icons/04-online.png` | The robot celebrating an online terminal. |

Created for this community guide using the **create-pixel-art** skill and
**Aseprite**, through `execute_lua` and `inspect_export`. Each original has six
editable layers. The saved sources were reopened before PNG export. Native
exports and enlarged previews were inspected on light and dark backgrounds;
the asset checker passed for all four illustrations. The guide only needs the
small PNGs, so editable art projects and development evidence are kept outside
this installation repository.

The robot is a cartoon interpretation of **[IMD NFT #221](https://explorer.imd.fun/agents/221)**,
referenced on 2026-09-26: angular dark mask, gold/violet eyes and cyan accents.
Its body, poses and props were newly drawn. The frog scenes were also newly
drawn. Credit for the original NFT design belongs to its creators; this is
community fan art, not an official IMD brand asset.

These are exported drawings, not Aseprite application files. No image-generation
API or paid media generation was used to make them.
